Kubuntu ships KDE Plasma, which makes tiling windows quick without a separate tiling WM.

{{< figure src="/images/blog/quick-tile-windows.png" title="Meta + arrow keys snaps a window to half the screen" >}}

### Try this

1. Focus the window you want to place.
2. Hold **Meta** (usually the Super / Windows key) and press an **arrow key**.
3. The window snaps to that half (or corner, with diagonals on many setups).

### Why it helps

You can compare docs and a terminal, or a browser and a chat client, without dragging borders. It works on both X11 and Wayland sessions in current Kubuntu releases.
