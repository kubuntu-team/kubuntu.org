Bienvenido a Kubuntu

Kubuntu es un sistema operativo que combina el poder de Ubuntu con el elegante escritorio KDE Plasma. Está listo para usar de inmediato, con todas las herramientas que necesitas para trabajar, crear y jugar.

Simple por defecto

Kubuntu está diseñado para ser fácil de usar desde el principio. El escritorio KDE Plasma viene con valores predeterminados cuidadosamente elegidos para que tu experiencia sea fluida y sencilla.

Potente cuando se necesita

Cuando tu flujo de trabajo no es de talla única, ¡Kubuntu te cubre! Explora una amplia gama de aplicaciones en Discover, personaliza el escritorio a tu gusto y haz que tu sistema sea realmente tuyo.

KRunner es el lanzador integrado del escritorio Plasma. Puede realizar muchas tareas: abrir archivos, convertir divisas o incluso controlar tu reproductor de música. ¡Lo tiene todo!
